# 上海高中知识点汇总 · 物理卷

> 按教材逐节整理的**上海高中知识点汇总**，用知识图谱的方式组织。本仓库是第一卷：**物理**（六册，166 个考点、498 道梯度例题、498 道自评题），支持「先测后学、会了就跳过」。
>
> 后续卷次：高中数学、语文、英语、化学、生物、历史、地理、政治 → 初中各科 → 小学各科。
>
> **状态**：v1.0 已发布 · **已发布内容持续更新中**（勘误 / 补例题 / 考频校准）｜ 更新记录见 [CHANGELOG.md](CHANGELOG.md)

---

## 一、为什么做这个

上海高中物理的教材体系与全国多数地区不同，市面上的教辅大多按人教版编排，章节对不上。孩子复习时经常遇到两个问题：

1. **不知道哪里不会**——从头读到尾，会的地方浪费时间，不会的地方一带而过；
2. **坚持不下去**——纯文字讲义太枯燥，错题也没有回炉机制。

所以这套材料的核心不是"知识点汇编"，而是**一套可执行的判断流程**：

```
章级入口自评（10 题）→ 决定整章跳不跳
        ↓
考点级 30 秒自评（3 题）→ 决定这一节学多少
        ↓
例题 1/2/3（基础→常考→综合）→ 检验
        ↓
限时挑战 90 秒 → 练速度
        ↓
错题打码 → 隔天重做 → 三天后换数字 → 销账
```

## 三、一张卡片长什么样

每个考点固定 8 段，从上往下读即可：

| 段落 | 作用 |
|---|---|
| **⚡ 先猜一下** | 一道反直觉的小问题，故意不给答案，制造认知冲突 |
| **30 秒概述** | 两三句话讲清"这东西解决什么问题" |
| **30 秒自评** | 3 道题，答案紧跟其后 |
| **原理与公式** | 逐条列出，带符号说明 |
| **适用条件** | 写清"什么时候不能用" |
| **易错边界** | 3 条以内，具体到错在哪一步 |
| **例题 1 / 2 / 3** | 难度递增，每道含解析、陷阱、变式 |
| **✅ 接下来做什么** | 按"对了几道"给出走法 + 按年级的过关线 |

## 六、重新构建

```bash
bash build/make.sh
```

依赖：`python3`、`python-docx`、`openpyxl`、`markdown`、`matplotlib`、LibreOffice、Google Chrome。

**改内容只改 Markdown**，重跑这条命令，四份成品同步更新。不要直接改 `输出/` 里的文件——下次重建会被覆盖。

## 七、几个设计取舍

**① 公式用纯文本写，构建时转 LaTeX。**
源文件里写 `x = v₀t + ½at²`，`mathfmt.py` 自动转成 `x = v_0t + \frac{1}{2}at^2`，交给 MathJax 排版。这样写内容的人不需要懂 LaTeX，改起来也方便。

**② PDF 由 HTML 直接打印，而不是 Word 转 PDF。**
Word 无法运行 MathJax，用 Word 转出来的 PDF 公式是图片拼贴，和网页不一致。现在两者同源，逐字一致。

**③ 配图优先用线条图，不用彩色照片。**
教材里很多彩色实拍图（阴极射线管、左手定则手绘图），打印费墨且缩小后模糊。所以配图以黑白矢量图为主，只在关键处引用课本线条图并转灰度。

**④ 三层难度分级（L1/L2/L3）。**
同一张卡，高一做到例题 1 即可，高二做到例题 2，高三要例题 3 和变式都对——不写三套内容，靠"过关线"区分。

## 八、已知限制

1. **考频标注是经验判断**，没有逐题统计历年上海等级考真题。
2. **含中文的公式仍是文本**（如"P损"），MathJax 不支持中文符号。
3. **DOCX 版公式为图片**，与 PDF/HTML 的排版不完全一致。
4. **教材版本**按现行上海高中物理教材编排；不同印次若有调整，以手头教材为准。

## 九、持续更新与路线图

这不是一个做完就归档的项目。**物理只是第一卷**，后续会按同一套方法论扩展到其他学段与学科。

| 阶段 | 范围 | 状态 |
|---|---|---|
| 一 | **高中物理**（六册，166 考点） | ✅ 已完成 |
| 二 | 高中数学、化学、生物 | 规划中 |
| 三 | 高中语文、英语、历史、地理、政治 | 规划中 |
| 四 | 初中各科 | 规划中 |
| 五 | 小学各科 | 规划中 |

**"同一套方法论"指什么：**

1. 按教材目录逐节拆分，一个考点对应一个可独立命题的单元；
2. 每个考点配 3 道梯度例题（基础 / 常考 / 综合）+ 3 道自评题；
3. 章级入口自评，做对就跳过，不浪费时间；
4. 错题按类型打码，隔天重做、三天后换数字；
5. 一套 Markdown 源，自动生成 PDF / HTML / Excel / Word 四种格式。

不同学科会调整细节（比如语文英语重语料、数学重题型变式），但"先测后学、错了能回炉"的骨架不变。

**已发布的内容同样会持续更新，不会停在 v1.0：**

- **勘误**：物理内容一旦发现错误（尤其是例题数据不自洽、量纲不对），会立即修订并记录在 CHANGELOG；
- **补强**：高频考点会增加变式题，低频考点会在后续版本补充说明；
- **校准**：考频标注目前是经验判断，后续会按历年真题统计逐步替换；
- **同步**：每次更新都会重跑构建，四份成品（PDF / HTML / Excel / Word）一起更新，不会只改一处。

**怎么跟进：**

- 点右上角 **Star** 或 **Watch → Releases only**，更新时会有通知；
- 在 **Issues** 里说想要哪一科，我会按呼声排优先级；
- 每个学科独立成库，互不影响，目前这个仓库只放物理。

> 说明：一个人的产能有限，物理这套做了完整的 109 节覆盖，后面的学科会**先出骨架再逐章填充**，不会一次性给全。
